# v1.0 release checklist

Purpose: choose a satellite or load an orbit, inspect movement and station visibility, and save useful results.

## First milestone

- [x] Explicit path recording, Stop, Save / Save As, and reopen in replay; discard unsaved drafts on restart/normal exit.
- [x] Flushed recovery journals and discovery on next launch.
- [x] Incomplete-final-line recovery without modifying original journals.
- [x] Pass start/end, peak elevation, duration, and click-to-replay for a loaded orbit.
- [x] Independent analytic pass tests and recording/recovery round trips.

## Before calling this v1.0

- [ ] Select a real catalog satellite as the primary tracked object, with pass predictions.
- [ ] Display settings: resolution, windowed, fullscreen and borderless fullscreen.
- [ ] Save and restore complete sessions, including cameras, stations, physics and replay files.
- [ ] Show orbit source, element age, UTC and prediction mode consistently across views.
- [ ] Validate operationally relevant propagation/pass cases against an established independent implementation.
- [ ] Improve near-grazing pass detection beyond the initial 10-second search cadence.
- [ ] Test release packaging on a clean Windows machine, including missing assets, offline startup and unavailable audio.
- [ ] Publish versioned downloads, a concise onboarding guide and consolidated third-party credits.
- [ ] Run an unassisted usability test: find a pass, replay it, save work and reopen it.

Attitude control, atmospheric entry and CFD remain experimental pending further validation. Synthetic recordings are explicitly distinguished from observations. No v1.0 version bump yet.
