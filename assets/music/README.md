# Local music library

The player scans this directory for MP3, WAV, Ogg Vorbis and FLAC files. Tracks are played in filename order, so numeric filename prefixes can define the playlist. The six agreed 2003 Toyota Corolla recordings are included; see CREDITS.md for permission and sources.json for download provenance and checksums. The first automatic track fades in after a randomized 45-60 second delay; a file named "End of the winter" also fades in whenever it starts.

Music recordings are separate from sattrak's MIT-licensed source code. Each distributed recording must be listed with its own permission and attribution in [CREDITS.md](CREDITS.md).
