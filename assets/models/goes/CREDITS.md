# GOES-R

Credit: NASA, GOES spacecraft model.

Source: https://science.nasa.gov/mission/goes-spacecraft-3d-model/

Original: https://assets.science.nasa.gov/content/dam/science/missions/goes/spacecraft/3dmodel/GOES-R.glb

Downloaded September 12, 2026. NASA media usage guidelines apply: https://www.nasa.gov/nasa-brand-center/images-and-media/
No NASA endorsement is implied. This asset is separate from the software's MIT license.

Converted with scripts/bake_spacecraft.py: static node transforms, centering, material grouping, base-color textures including UV transforms, and roughness. Source meter scale retained. Rendering uses approximate lighting and alpha cutouts, without normal/metallic maps or full glTF PBR. See conversion.json for geometry bounds and source checksum. Selecting the model does not automatically select a geostationary orbit or change simulation mass or inertia.
